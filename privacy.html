سیاست حریم خصوصی Kami AG

  • اپ فقط با اجازهٔ خود کاربر به Google Drive او وصل می‌شود و فقط به فایل‌هایی دسترسی دارد که خودش ساخته (دسترسی drive.file).
  • از این دسترسی فقط برای ذخیره و بازیابی فایل بکاپ خود اپ در درایو کاربر استفاده می‌شود.
  • هیچ دادهٔ گوگل کاربر فروخته، به اشتراک گذاشته یا به شخص ثالث فرستاده نمی‌شود و برای تبلیغات استفاده نمی‌شود.
  • کاربر هر زمان می‌تواند دسترسی را از تنظیمات اپ یا از صفحهٔ myaccount.google.com/permissions لغو کند.

Privacy Policy (English)

  • Kami AG connects to the user's Google Drive only with the user's explicit consent and only uses the drive.file scope, which gives access solely to files the app itself creates.
  • This access is used only to store and restore the app's own backup file in the user's Drive.
  • No Google user data is sold, shared, transferred to third parties, or used for advertising. Use of data received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
  • Users can revoke access at any time in the app settings or at myaccount.google.com/permissions.
